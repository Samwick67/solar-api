# Solar Tracking System

A responsive web application developed for the **ITDA301 Solar Tracking System** project. This project demonstrates the concept of an intelligent solar tracking system through a clean, interactive interface built entirely with HTML, CSS, and JavaScript.

The application showcases the project design, system information, and solar tracking concepts in a lightweight web application that can be accessed from any modern browser.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/yourusername/solar-tracking-system.git
cd solar-tracking-system
```

Open `index.html` in your preferred web browser, or use a local development server such as the VS Code **Live Server** extension.

## Project Purpose

This project was created as part of the **ITDA301** module for the Bachelor of Information and Communication Technology (Internet of Things) at the Durban University of Technology.

It serves as a demonstration of a solar tracking system, presenting the project's objectives, design, and functionality through an interactive web interface.
